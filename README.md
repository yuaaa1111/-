# BEAT CHRONO - 音ゲー用 BPM & n分音符リズム可視化チェッカー

音ゲーマー（プロセカ、Arcaea、チュウニズム、beatmania IIDX、SDVX、太鼓の達人など）のための、テンポ・リズム可視化＆打鍵タイミング確認Webアプリケーションです。

AI感謝
---

## 主な機能

1. **BPM & n分音符のリアルタイム設定**
   - **BPM自由設定**: 20〜600まで細かく調整可能
   - **音符分割**: 4分、6分、8分、12分(3連符)、16分、24分(6連符)、32分、48分、64分音符、およびカスタムn分音符に対応
   - **打鍵間隔(ms)＆秒間打鍵数(NPS)**: 瞬時に計算し、音ゲー難易度基準でスピード帯を表示

2. **3つの表示ビジュアライザー（見た目）**
   - **縦落ちモード**: beatmania / プロセカ / SDVXスタイルの落下ノーツ（2レーン交互振り分け・トリル対応）
   - **横スクロールモード**: 太鼓の達人 / Muse Dashスタイルの左右スクロール
   - **サークルモード**: maimai / メトロノームスタイルの外周パルス

3. **高精度Web Audio APIサウンド（音）**
   - タイマーのズレを排除した高精度ルックアヘッド・スケジューリング
   - **選べる音色**:
     - Arcade Perfect（音ゲー打鍵音）
     - Cyber Laser（シンセレーザー）
     - Taiko（太鼓のドン/カッ）
     - Digital Metronome（電子メトロノーム）
     - Woodblock（木魚）
     - Kick & Snare（ドラム）
   - 小節頭/各拍のアクセント音や、背景4分メトロノームの同時再生機能

4. **1小節リズムシーケンサー (ON/OFFエディタ)**
   - 均等連打だけでなく、「裏拍のみ」「付点8分」「ガロップ（乱打）」「交互打ち」などのリズムパターンをワンタップで編集・再生可能
   - 現在再生中の位置が光るリアルタイムステップライト

5. **タイミング練習＆判定チェッカー**
   - 画面の「TAP」ボタン、またはキーボードの `[Space]` / `[D]` / `[K]` で実際にリズムに合わせて打鍵可能
   - 判定ラインとのズレ（±ms）をリアルタイムに計算し、**PERFECT / GREAT / GOOD / EARLY / LATE** を表示
   - **TAP BPM**: リズムに合わせてタップしてBPMを逆算測定

##  キーボードショートカット

| キー | 動作 |
|---|---|
| `Space` | 再生 / 停止（再生中はセンター打鍵） |
| `D` | 左レーン打鍵 (TAP L) |
| `K` | 右レーン打鍵 (TAP R) |
| `T` | TAP BPM (タップテンポ測定) |
| `↑` / `↓` | BPMを ±5 調整 |
